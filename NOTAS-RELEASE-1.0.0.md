# KPlayer 1.0.0 — notas sugeridas

Player de músicas, vídeos e rádio online para R36S com dArkOS / PortMaster.
Inclui sete temas, biblioteca local, letras compatíveis, fila, busca de mídias,
rádios do usuário e catálogo Radio Browser, além de PT-BR, inglês e espanhol.

Requer SDL2, ALSA e plugins VLC compatíveis no sistema; rádio exige internet.
Consulte README.pt-BR.md e docs/INSTALL.md antes de instalar. Faça backup das
mídias, rádios e configurações antes de atualizar.

Estado antes da publicação: a correção do rádio foi relatada funcionando no
R36S; os temas, a barra de carregamento e a compilação ARM64 desta versão
precisam de teste. O atualizador automático é experimental, depende de Python 3,
e ainda não foi testado no R36S; consulte ATUALIZADOR-EXPERIMENTAL.md.
