# Controls / Controles

B confirms/opens and A goes back/cancels. SELECT opens or closes Settings. START pauses/resumes active media. Software volume controls are not used; adjust volume with the console's physical/system controls.

B confirma/abre e A volta/cancela. SELECT abre ou fecha Opções. START pausa/continua a mídia ativa. O aplicativo não altera o volume por software; use os controles físicos/do sistema do console.

| Screen / Tela | Buttons / Botões |
| --- | --- |
| Welcome / Boas-vindas | D-pad changes language; B saves and starts; Y opens terms; SELECT settings / Direcional muda idioma; B salva e inicia; Y abre termos; SELECT opções |
| Terms / Termos | Left/right or up/down changes page; A returns / Direcionais mudam página; A volta |
| Dashboard | D-pad selects card; B opens; X returns to player; Y or SELECT settings / Direcional escolhe; B abre; X volta ao player; Y ou SELECT opções |
| Online Radio / Rádio Online | Up/down selects a station; left/right changes category; B plays/pauses; A returns home; Y refreshes; L1/R1 plays previous/next station / Cima/baixo seleciona estação; esquerda/direita muda categoria; B toca/pausa; A volta; Y atualiza; L1/R1 toca anterior/próxima |
| Automatic library / Biblioteca automática | Music and Video recursively search `midias`, `/roms` and `/roms2`; files below 50 KB are ignored; B plays; A returns; Y rescans / Músicas e Vídeos pesquisam `midias`, `/roms` e `/roms2`; arquivos menores que 50 KB são ignorados; B toca; A volta; Y pesquisa novamente |
| File browser / Explorador | Up/down selects; B opens; A parent/locations/home; left/right filters; Y refreshes; X player / Cima/baixo seleciona; B abre; A sobe/volta; esquerda/direita filtra; Y atualiza; X player |
| Music / Música | Y opens Lyrics; X opens Queue and switches Queue/Folder; B pauses in Lyrics or opens/plays list selection; START always pauses / Y abre Letras; X abre Fila e alterna Fila/Pasta; B pausa nas letras ou abre/toca a seleção; START sempre pausa |
| Music navigation / Navegação musical | Up/down moves selection or scrolls plain lyrics; left/right seeks 10 seconds; L1/R1 changes track / Cima/baixo navega ou rola letras simples; esquerda/direita busca 10 s; L1/R1 troca faixa |
| Music back / Voltar na música | A goes to the parent in Folder; otherwise home. Favorite marking is in Settings / A sobe uma pasta no painel Pasta; nos outros painéis, vai à dashboard. Favorita fica nas opções |
| Video / Vídeo | B pauses; A stops and returns home; X toggles controls; Y or SELECT settings; left/right seeks 10 s; L1/R1 changes media; L2/R2 seeks 5 s / B pausa; A encerra e volta; X oculta/mostra controles; Y ou SELECT opções; esquerda/direita busca 10 s; L1/R1 troca mídia; L2/R2 busca 5 s |
| Settings / Opções | Up/down selects; left/right or B changes/opens; A, Y or SELECT returns; “Exit KPlayer” closes the app / Cima/baixo seleciona; esquerda/direita ou B altera/abre; A, Y ou SELECT volta; “Sair do KPlayer” fecha o app |

| GPTOKEYB key | Console |
| --- | --- |
| Backspace | A |
| Enter | B |
| Space | X |
| M | Y |
| Tab | START |
| F1 | SELECT |
| Arrow keys | D-pad |
| Q / E | L1 / R1 |

The bundled PortMaster GPTOKEYB profile is `ports/kplayer/kplayer.gptk`. Keyboard Escape remains an emergency exit for desktop testing and is not mapped to SELECT.
